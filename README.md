# livelibot

Business assistance chatbot for Baguio City and Benguet. Answers questions
using retrieval-augmented generation (RAG) over a local knowledge base, with
answers generated by a Groq-hosted LLM.

## Requirements

- Python 3.10+
- Internet access (the embedding model is downloaded on first run, and answers
  are generated via the Groq API)

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux

pip install -r requirements.txt
```

Set your Groq API key as `CHAT_API_KEY` in `config/llm_config.py`, and adjust
`CHAT_MODEL`, `N_RESULTS`, or `MAX_DISTANCE` there if needed.

On first run, the `sentence-transformers/all-MiniLM-L6-v2` embedding model is
downloaded automatically from Hugging Face (cached afterwards).

## Build the knowledge base

The repository already ships an indexed `chroma_db`. Rebuild it only after
changing anything in `documents/`:

```bash
python ingest.py
```

Supported source formats: `.txt`, `.md`, `.pdf`, `.docx`, `.csv`, `.json`.

## Run the app

```bash
python main.py
```

The server starts at http://127.0.0.1:5232 (debug mode on).

## Project layout

```
main.py                 Flask entry point (port 5232)
ingest.py               Rebuilds the vector database from documents/
config/                 LLM, RAG, and environment settings
rag/                    Document loading, embeddings, Chroma vector store
llm/assistant.py        Prompt assembly and Groq chat completion calls
web/                    Flask app factory, chat route, templates, static files
documents/              Knowledge base source files
chroma_db/              Generated Chroma vector database
```
